# PenduTKinter

Jeu du pendu développé avec Python et Tkinter.

## Description

Ce projet est une version du jeu du pendu réalisée en Python avec l’interface graphique Tkinter.  
Par défaut, le jeu utilise un mode Pokémon, mais il est possible de passer en mode normal via le bouton dédié.

## Règles du jeu

- Le joueur doit deviner un mot caché ;
- Il propose une lettre à la fois ;
- Si la lettre est correcte, elle s’affiche dans le mot ;
- Si la lettre est fausse, le pendu se complète ;
- Le jeu se termine lorsqu’on a trouvé le mot ou lorsqu’on a épuisé les essais.

## Important

- Il faut écrire les lettres en majuscule ;
- Le mode Pokémon est activé par défaut ;
- Pour jouer avec des mots classiques, il faut cliquer sur le bouton "Mode Normal".

## Technologies utilisées

- Python
- Tkinter
